CONFIGURATION / THREE CONNECTIONS

把连接配好，
研判就绪。

按顺序配置新闻检索、分析模型和数据库。每项都可以先测试，再保存。已有 Key 和密码不会在网页中回显。

01 / SEARCH读取中…

DeepSeek 检索

Search 发现候选，Fetch 提取正文。这里也可以指定默认分析使用的 DeepSeek 模型与官方思考档位。

获取模型后可按 DeepSeek 返回的支持档位选择；自动表示沿用模型默认值。

配置保存在本机 data/deepseek-config.json；旧版 .env 仍可作为后备。
02 / REASONING读取中…

分析模型 API

检索式规划、长篇筛选和风险研判共用这个接口。支持 OpenAI 与 Anthropic 格式；不配置时沿用 DeepSeek。

自动表示沿用服务默认值。获取模型后会优先显示接口返回的支持档位。

配置保存在本机 data/analysis-config.json；更换服务链接时需重新填写 Key。
03 / STORAGE读取中…

SQL 入库

连接本机 MySQL / MariaDB。保存时创建研判、新闻主库与版本链接表，并导入已有本地记录。

连接信息保存在本机 data/mysql-config.json；密码不会回显。
