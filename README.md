# 溯源 Suyuan：涉华政经舆情风险研判系统

溯源是一套面向涉华政治经济议题的本地舆情研究系统。它将多语种新闻、公开社媒、论文和浏览器剪藏汇入持续积累的研究库，围绕可核查的原文证据生成风险研判，并记录同一议题在不同时间的变化。

## 核心能力

| 能力 | 作用 |
| --- | --- |
| 多语种新闻研究 | 按议题与时段检索，去重同稿转载，筛选长篇分析、深度报道、评论与社论 |
| 社媒与论文研究库 | 汇集公开社媒材料和论文 PDF，结合新闻构成可复用的本地知识库 |
| 证据驱动的风险研判 | 从代表材料归纳观点和风险点，保留报道链接、原文段落与论文页码 |
| 跨期主张档案 | 追踪已保存议题的新增材料、反向证据及风险判断变化 |
| 浏览器剪藏与融文数据源 | 导入浏览器中可阅读的文章；在具备账号权限时接入融文记录 |

## 项目特点

溯源把一次性检索结果沉淀为可检索、可复核的研究资料。后续研究可以直接利用已有材料，并围绕同一风险主张比较不同语种、来源和时段的证据，而不必每次从空白对话开始。

系统将新闻原文、社媒帖子、论文内容和平台匹配片段按来源类型保存。研判结果保留证据入口，便于回看材料、检查翻译和修正判断。

## 能力边界

“全量检索”指当前检索式和时段内接口实际返回的候选，不代表穷尽全网。融文导出记录可能只有元数据和短匹配片段，不能当作新闻全文。浏览器剪藏依赖当前页面已能阅读的内容；自动识别与风险判断仍需人工核对。
