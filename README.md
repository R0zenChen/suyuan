# 溯源 Suyuan

### 涉华政经舆情风险研判系统

**从多语种报道中发现风险，用原文证据解释判断，持续追踪议题变化。**

溯源是一套在本机运行的舆情研究工具，面向涉华政治经济议题。它把新闻、公开社媒、论文和浏览器剪藏汇入同一研究库，帮助研究者从大量材料中找出有代表性的观点与风险点，并把每个判断连接到可回看的来源。

[下载最新版本](https://github.com/R0zenChen/suyuan/releases) · [使用说明](使用说明书.md) · [功能与数据说明](docs/功能与数据说明.md)

## 让研究从一次回答变成持续积累

围绕同一议题，研究者往往需要反复查找不同语言的报道，判断转载是否重复，核对观点来自哪里，再比较新证据是否改变了先前结论。溯源将这些步骤放进一个工作台：检索结果进入研究库，研判结果成为档案，下次打开议题时可以继续使用已有材料并查看变化。

它重点解决三个问题：

1. **材料分散**：把多语种新闻、公开社媒、论文 PDF 和网页剪藏放在同一个可检索的资料库中。
2. **判断难复核**：风险点关联报道链接、原文段落和论文页码，同时保留候选材料的筛选记录。
3. **议题难追踪**：保存同一主张的跨期证据、反向材料和风险判断，展示相较上次研究的新变化。

## 一次研判如何完成

```text
输入议题与时间范围
    ↓
多语种检索与分时段发现
    ↓
正文提取、同稿去重、深度材料筛选
    ↓
观点归纳、风险点生成、原文证据关联
    ↓
保存研究档案，按需进行增量追踪
```

新闻检索默认覆盖英语、西班牙语、德语、法语、俄语、阿拉伯语、葡萄牙语、韩语和日语，也可以根据议题调整语种。系统优先选择长篇分析、深度报道、署名评论与社论；对原站无法取得正文的材料，可尝试公开快照或标明来源的公开版本。研判页面同时展示代表报道与全部候选的处理结果，方便回看取舍依据。

## 核心功能

### 新闻 × 社媒 × 论文的研究库

新闻、公开社媒帖子、论文 PDF 和剪藏文章进入本地库后，可以按关键词和语义检索。研究者能够直接对已有材料提问，回答附来源入口；论文材料在可识别时附页码。遇到结论相反的论文，系统分别保留两篇原文及其证据，供并列核对。

### 有来源的风险研判

系统从代表材料中归纳观点分歧与风险点，引用相应报道的原文段落。每篇候选报道保留来源、提取状态、去重结果和入选或排除原因；证据核验工作台允许研究者标记“已核实”“有争议”或“不采用”，并记录理由。

### 议题与主张的跨期档案

已保存的研究可持续补充新材料。档案记录本轮出现的支撑证据、反向证据、新来源和判断变化，让研究者先看到“相比上次发生了什么”，再进入本轮报告与原文。每日增量监测在本地服务运行时执行。

### 浏览器剪藏与 PDF 入库

溯源 Clipper 可以从当前已能阅读的网页预览并修订标题、日期、来源和正文，然后保存到研究库。论文 PDF 可在网页或扩展中手动选择导入；系统先提取可复制文字，对扫描页尝试本地 OCR，并尽可能识别题名、作者、年份和 DOI。识别质量不足时，可选择使用已配置的多模态分析接口辅助处理。

### 可选的融文数据源

拥有融文账号权限的研究者，可使用内置研究台按时段检索、下载并导入记录。融文导出的匹配片段会单独标记，便于与已取得的报道全文区分。

## 产品入口

| 入口 | 可以做什么 |
| --- | --- |
| **工作台** | 输入议题、观察检索进度、阅读代表报道和风险研判、打开历史档案 |
| **研究库** | 浏览新闻与社媒、导入论文、检索资料并进行库内问答 |
| **配置中心** | 管理 DeepSeek 检索、SQL 连接和分析模型接口 |
| **溯源 Clipper** | 将当前可阅读网页或本地 PDF 加入研究库 |

## 下载与使用

在 [Releases 页面](https://github.com/R0zenChen/suyuan/releases)选择对应系统的 ZIP：

| 系统 | 文件名 |
| --- | --- |
| Windows x64 | `Suyuan-v版本号-windows-x64.zip` |
| macOS Apple Silicon | `Suyuan-v版本号-macos-arm64.zip` |
| Linux x64 | `Suyuan-v版本号-linux-x64.zip` |

系统使用 Python 3.12 和 MySQL／MariaDB；融文功能另需 Node.js 22+。各系统的启动入口、配置步骤和浏览器扩展安装方法见[使用说明书](使用说明书.md)。

## 适用边界

检索覆盖的是当前接口在指定检索式和时段内返回的材料，不能视为全网穷尽。融文匹配片段与报道全文分别呈现。网页剪藏取自当前浏览器可阅读的页面；来源、译文、论文元数据及模型生成的风险判断仍应由研究者核对。
