# 溯源 Suyuan

**涉华政经舆情风险研判系统**

溯源面向涉华政治、经济议题的持续研究。系统把多语种新闻、公开社媒、论文 PDF、浏览器剪藏和可选的融文记录汇入本地研究库，以可回看的原文证据支撑风险研判。研究者可以从一次检索进入材料筛选、观点归纳和风险判断，也可以在同一议题上持续积累资料，比较新材料与旧判断之间的变化。

## 项目定位

通用 AI 深度研究适合回答单次问题；溯源侧重长期保存研究材料和判断过程。每篇候选报道会留下来源、抓取状态、入选或排除原因，研判中的风险点关联具体证据。再次研究相同议题时，系统可以检索已有库、补充新材料，并展示主张、新增证据及风险判断的跨期变化。

研究过程可以概括为：

**设定议题与时段 → 多语种发现材料 → 提取和去重 → 筛选深度报道 → 归纳观点与风险点 → 保存证据和档案 → 增量复核。**

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 多语种新闻检索 | 按日期分段生成检索式；默认覆盖英语、西班牙语、德语、法语、俄语、阿拉伯语、葡萄牙语、韩语和日语，也可按议题调整语种。DeepSeek Search 发现候选，Fetch 提取可访问正文。 |
| 材料筛选与去重 | 合并同一报道的不同转载入口，优先筛选长篇分析、深度报道、评论和社论；保留未入选候选及原因。原站无法取文时，可尝试公开快照或注明来源的公开版本。 |
| 风险研判 | 从代表材料提炼观点分歧和风险点，将风险判断关联到报道链接与原文段落；材料不足时显示待补状态。 |
| 新闻 × 社媒 × 知识库 | 将新闻、公开社媒帖子、论文段落与剪藏内容写入 MySQL，建立本地词面和向量检索索引，支持附来源的库内问答。 |
| 论文 PDF 入库 | 提取 PDF 文字，对扫描页使用本地 OCR；尝试识别标题、作者、年份和 DOI，保留页码。可选用配置的多模态模型补救低质量识别页。 |
| 浏览器剪藏 | 在 Chrome／Edge 中预览并修订当前可阅读网页的标题、日期、来源和正文，再保存到本地库；扩展也提供手动选择 PDF 的入口。 |
| 跨期研究档案 | 保存研判、证据核验记录和主张变化；已保存议题可在本地服务运行时进行每日增量监测。 |
| 可选融文来源 | 在有账号权限时使用内置融文研究台检索、分段下载并入库；导出中的匹配片段与新闻全文分别标记。 |

## 研究库如何工作

新闻、社媒帖子、论文和剪藏内容首先保存在本地 MySQL。系统为可用正文建立检索索引，问答时结合关键词与语义召回相关段落，再将命中证据交给已配置的分析模型。回答附带来源入口；论文证据在可识别时附页码。两篇结论相反的论文会分别保存，系统不会用其中一篇覆盖另一篇。

配置中心分别管理 **DeepSeek 检索、MySQL 入库、分析模型 API**。分析接口支持 OpenAI 兼容和 Anthropic 兼容格式；模型列表能由服务商提供时可获取，不能提供时可手填。密钥、数据库密码、原始论文和研究数据只保存在本机，不随源码或发布包上传。

## 典型使用场景

- **议题初判**：输入涉华政经议题和时间范围，查看代表报道、不同语种的主要观点、风险点及其原文依据。
- **持续追踪**：保存议题后复查新增材料、反向证据与风险判断变化，避免每次从空白检索开始。
- **证据补全**：把浏览器中已能阅读的文章或手头论文 PDF 加入研究库，与新闻和公开社媒材料一起检索。
- **资料复核**：在档案中查看全部候选、去重结果、提取状态和排除原因，人工核对原发来源、译文及引文是否支持结论。

## 页面与组件

| 入口 | 内容 |
| --- | --- |
| 工作台 | 议题输入、检索进度、代表报道、风险研判与已保存档案 |
| 研究库 | 新闻、社媒、论文、剪藏内容的浏览、PDF 导入与库内问答 |
| 配置中心 | 检索接口、分析模型和 SQL 连接的独立配置与连接测试 |
| 溯源 Clipper | 浏览器当前页正文剪藏与本地 PDF 入库 |

系统在本机运行。核心服务使用 Python，研究库使用 MySQL／MariaDB；融文数据源需要 Node.js 和有权限的账号。首次安装依赖及首次下载本地向量模型时需要网络。具体安装、配置和操作见[使用说明书](使用说明书.md)，检索口径和数据处理细节见[功能与数据说明](docs/功能与数据说明.md)。

## 下载

[GitHub Releases](https://github.com/R0zenChen/suyuan/releases) 提供按目标系统构建和检查的安装 ZIP：

| 系统 | 发布包 | 启动入口 |
| --- | --- | --- |
| Windows x64 | `Suyuan-v版本号-windows-x64.zip` | `install-windows.cmd`、`启动溯源.exe` |
| macOS Apple Silicon | `Suyuan-v版本号-macos-arm64.zip` | `start-macos.command` |
| Linux x64 | `Suyuan-v版本号-linux-x64.zip` | `start-linux.sh` |

发布包包含源码、浏览器扩展和对应系统的启动入口；Python、MySQL 及可选的 Node.js 由使用者在本机准备。三个包不包含个人 API 配置、账号、数据库或论文文件。

## 使用边界

检索覆盖的是当前接口在所选检索式和时段内返回的候选，不能代表穷尽全网。公开快照和转载只在取得可核对正文、通过筛选后才作为研判材料。融文匹配片段不能当成报道全文。浏览器剪藏依赖当前页面已有的可阅读内容，不提供对付费或登录限制的自动破解。自动提取、翻译、论文元数据识别和风险判断都需要人工复核。
